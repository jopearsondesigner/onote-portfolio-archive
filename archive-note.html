About this archived site

This is a visual reconstruction of an oNote marketing website originally designed and developed with WordPress, Timber/Twig, Tailwind CSS, and custom artwork.

Some functions, including product registration, login, CRM forms, historical documentation and external support portals, are not part of this portfolio demonstration.

Account features

Login and sign-up were part of the original live service; this static reproduction does not create accounts.

Documentation

Original product documentation was hosted separately and has not been reconstructed here.

Support

The historical support portal is not part of this preview.

Contact and forms

Original company contact addresses and HubSpot forms are disabled to avoid sending messages to an inactive or unrelated service.

Use cases

The original use-cases content is not included in this recovery package.

Other historical content

This original destination was not recovered in the supplied files.
